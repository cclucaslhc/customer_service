# 知识库与 Agent 评测

## 运行方式

评测使用临时数据库和临时知识目录，不读取生产数据库、上传文档或已保存的模型密钥。

```powershell
.\.venv\Scripts\python.exe scripts\evaluate.py --repetitions 30
```

命令将 JSON 报告输出到标准输出。`--repetitions` 控制每条正例用于延迟统计的重复次数，默认是 30。指标低于质量门槛时命令会返回非零退出码，可直接接入 CI。门槛是在冻结 v2 数据集并完成首次运行后设置的回退告警线，低于首次基线并保留余量，不是期望刷到的目标分数。

## 知识库指标

固定数据集位于 `tests/fixtures/knowledge_retrieval_eval.json`，包含 15 篇内容相近的合成企业文档、15 条基础冒烟查询、40 条挑战查询、5 条简单负例和 15 条困难负例。挑战集覆盖相似文档、错别字、口语化表达、改写和弱关键词问题；困难负例会复用文档中的型号与术语，但所问事实并未出现在资料中。

- `Recall@1`：正确文档排在第一位的正例比例。
- `Recall@3`：正确文档出现在前三位的正例比例。
- `MRR@3`：正确文档在前三位排名倒数的平均值；未命中记为 0。
- `negative_rejection_rate`：范围外查询没有返回知识片段的比例。
- `latency_ms`：本机进程内端到端检索耗时，包含 SQLite 查询与确定性重排，不包含 HTTP 和模型生成时间。
- `challenge_by_category`：按相似文档、错别字、口语化、改写和弱信号拆分的 Recall/MRR，用于定位具体短板。
- `positive_failures` / `hard_negative_false_positives`：输出失败问题、期望文档和实际召回文档，避免只有汇总分数而无法诊断。

该数据集仍为合成数据，适合工程回归和算法对比，不代表生产环境的泛化能力。用于简历或对外材料时必须同时披露样本数和数据性质。

## v2 首次冻结基线

2026-08-26 在本机隔离数据库中首次运行冻结后的 v2 数据集，未根据结果修改题目或检索实现：

| 范围 | Recall@1 | Recall@3 | MRR@3 |
| --- | ---: | ---: | ---: |
| 全部 55 条正例 | 80.0% | 89.1% | 0.842 |
| 40 条挑战题 | 80.0% | 87.5% | 0.833 |
| 口语化 | 25.0% | 50.0% | 0.375 |
| 改写 | 87.5% | 100% | 0.917 |
| 相似文档 | 100% | 100% | 1.000 |
| 错别字 | 100% | 100% | 1.000 |
| 弱关键词 | 83.3% | 83.3% | 0.833 |

5 条简单负例拒答率为 40%，15 条困难负例拒答率为 0%。这表明当前检索器能较好地区分相似文档和容忍局部错别字，但对口语化表达及“文档相关、答案缺失”的问题处理明显不足。困难负例暂不设置通过门槛，保留为后续改进查询理解、证据覆盖判断和答案可回答性判定的基准。

在 1,650 次本机检索中，本轮 P50/P95 延迟约为 5.5/8.8 ms；延迟会随硬件、数据量和缓存状态变化，不应直接外推为生产性能。

## Agent 编排指标

固定场景位于 `tests/fixtures/agent_orchestration_eval.json`，覆盖知识检索、营业时间、订单、物流、退款资格、人工转接和无需工具的直接回答。

- `workflow_conformance_rate`：工具、最终回答、SSE 终止事件、引用/人工表单和数据库运行状态均符合预期的场景比例。
- `tool_execution_success_rate`：包含工具调用的场景中，指定工具实际完成且整个运行成功的比例。
- `latency_ms`：使用本地 `FunctionModel` 时的编排开销，不包含真实大模型网络和推理耗时。

Agent 评测使用脚本化模型明确发出预期工具调用，因此只能衡量系统编排和事件链路，不能声称是“大模型工具选择准确率”。真实模型评测需要用户在管理界面明确提供测试密钥，并建立包含期望工具、关键参数和答案判定规则的独立盲测集。

## 建议的生产阶段指标

上线试运行后应在脱敏数据上补充：

- 真实模型工具选择准确率和参数正确率；
- 引用支持率、答案完整率和事实错误率；
- 首 Token 延迟及端到端延迟的 P50/P95；
- 首问解决率、人工转接率、重复咨询率和用户满意度；
- 按问题类型、文档类型和模型版本分组的回归结果。

生产指标必须记录评测时间、样本量、数据切分、模型及提示词版本，避免因数据泄漏或口径变化产生不可比较的结果。
